# Bear游戏库

作者：**lostlybear**。Windows x64 便携式游戏库管理工具。

## 下载

前往 [最新发行版](https://github.com/BearYeah/bear-game-library/releases/latest)，推荐下载便携 ZIP，解压后运行 **Bear游戏库.exe**。

首次升级到 1.5 或更新版本 需要手动下载一次；随后默认启动时检查 GitHub Releases、后台下载新版本，在关闭 Bear 后安装。可在“补丁与设置”关闭自动检查/下载，或手动检查和安装更新。

升级时保留原来的 **data** 文件夹。无需重新添加游戏。自动更新沿用程序的代理设置，验证维护者发布签名、文件大小和 SHA256；客户端不需要 GitHub 账号或令牌。

## 功能

- 带封面的游戏库、Steam 公开资料搜索、手动 AppID 添加和 DLC 管理。
- 在线搜索和本地筛选独立；自动分配免费替代 ID。
- 配置保存、补丁安装/卸载、缓存清理与 Steam 正常重启。
- GreenLuma 普通模式安装、切换和通过 DLLInjector 一键启动。
- Steam 关键代码结构的只读兼容性检测。
- 签名更新、保留游戏库、更新失败回退。

静态兼容性检测不等于所有补丁功能均已实机验证。Steam 关键结构大改仍可能需要维护者适配，客户端不能自行修补未知变更；映射游戏的更新限制没有因此消失。工具更新后，Steam 目录中的补丁仍通过安装按钮应用。
